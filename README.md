## 工作顺序

1. 定义用途与硬条件；从厂商原始规格筛选候选。
2. 分渠道采集实测、长期使用反馈和缺陷报告；记录具体型号及代数。
3. 淘汰不合适型号，确定短名单。
4. 最后在淘宝、京东、拼多多、闲鱼核对每条商品的选中 SKU、价格、运费、优惠规则、配件和卖家信誉。
5. 做最终购买比较。任何下单、支付、联系卖家或账户修改均须用户明确授权。

## 研究原则

- 官方规格、独立测评、用户反馈和商家宣称分层记录。
- 明确区分已验证事实、用户主观体验和待验证猜测。
- 不把搜索列表的最低价当作目标 SKU 的价格。
- 不因型号名称相似就混用不同代产品的测评。
- 不公开本地购物浏览器的认证信息、账户资料或设备标识。
