# MIDI 控制器可复测测试方案

更新：2026-10-24。用途：把主观“手感好”“控制方便”转换成具体任务和观察项。**本阶段不收集零售价格。**

## 测试前提

- 目标系统：Windows 10/11；比较 FL Studio 与 Cubase。记录精确软件版本、控制器固件和所用驱动。
- 每款需记录完整型号、代数、键数、物理尺寸、USB/MIDI 接口和实际键床尺寸类别（mini / slim / full）。
- 尽量使用同一台电脑、同一个 VST 乐器和同一监听路径；关闭 VST 内部力度压缩和音效变化，统一音频缓冲。
- 任何测评仅展示某 DAW / OS 上的功能都不得自动推断另一个 DAW 也同样方便。
- 线下实测以原装官方固件为准；不要为测试刷入第三方固件。

## T1 琴键手感与音乐输入（最高优先级）

1. 同样速度与力度演奏 C 大调 2 八度上/下行、黑白键交错音型；观察是否需要显著额外力量。
2. 在 37 键范围弹 **左手低音 + 右手三和弦或单音旋律**，关注手指碰撞、键距与八度跨度。
3. 在相同 VST 钢琴音色上重复 pp、mp、ff 三档，观察是否容易稳定做出不同力度。
4. 快速三连音与重复同一键（包括黑键）各测试 20–30 秒，观察触发遗漏、回弹不一致。
5. 记录个人感受：底部触感、键噪、抖动、回弹、白键前端与靠内侧的触发差异。不得把喜好当测量事实。

## T2 MIDI 事件客观检查

- Windows 可以使用 MIDI-OX 或同类 MIDI Monitor **仅观察键盘原始 Note On/Off、velocity 及 CC**（需要确认具体 MIDI port 选择正确）。
- 每键采集多次 Note On velocity，观察压到底才触发、过于集中在高/低值、极少力误触等情况。
- 快速重按、多个连续和弦、模式切换后迅速输入：检查有无丢音/重复音/卡音。
- 区分 **控制器 MIDI 事件时间**、**DAW 处理延迟**、**音频接口缓冲** 和 **蓝牙音频延迟**。听到声音晚到本身无法直接证明 MIDI 发送出错。
- 单机固件 bug 先查发布版本：例如 SMK-37 Pro V016 的历史 MIDI latency fix，必要时对照更新前后的可复现步骤。

## T3 FL Studio 工作流

1. 首次接入和断开重连能否识别？必要步骤与耗时（人工记录）。
2. Play/Stop/Record、撤销、节拍器、步进音序器、Channel Rack、Mixer 参数是否能不摸鼠标完成？
3. 切换两个 VST，旋钮是否跟随对应参数？值是否跳变？返回以前工程设置是否保留？
4. 调用 Chord/Scale/Arp 功能时屏幕是否提供足够反馈？
5. 关闭/重开 FL Studio 复测所有映射。

## T4 Cubase 工作流

1. 检查官方脚本/控制模式支持以及安装说明；记录 Cubase 主版本。
2. 测试走带、录制、轨道选择、Mixer 控制、插件旋钮参数与轨道翻页。
3. 调用 MIDI Remote 及原厂脚本是否冲突？有无重复端口输入或参数跳变？
4. 重开 Cubase、改工程模板、重新插拔键盘，确认映射是否稳定。

## T5 生产力和扩展性

- 鼓垫（轻/重击、连续击打、aftertouch 与否）。
- 编码器响应（由最小到最大需要多少转、不同速度是否一致、是否可以快速细调）。
- 实体推子数量及是否有拾取模式；没有推子的型号，测试使用编码器混音的负担。
- Pitch/Mod 控制是实体轮还是触摸条，是否易于做渐变/颤音。
- 自带音序器 / Arp 与 DAW 的 MIDI 录制能否正确同步。
- 是否需要专有软件后台才能完成基本功能；软件注册及二手转让机制。
- 桌面占用：宽 ≤595 mm，**另记深度、USB 接头朝向、外接踏板/线材**。

## 候选 A/B 对照优先次序

| 对照组 | 想解决的问题 |
|---|---|
| MiniLab 37 vs Launchkey 37 MK4 | Slim 琴键和全尺寸键谁更适合长期旋律/和弦输入？ |
| Launchkey 37 MK4 vs Mini 37 MK4 | 同一产品系列的小键床是否真的值得节省约 79 mm 宽度？ |
| Launchkey 37 MK4 vs FLkey 2 37 | 主用 FL Studio 时专用控制的收益，是否值得放弃一部分 Cubase 便利？ |
| MiniLab 37 vs KeyStep 37 mk2 | DAW 控制/推子/鼓垫与触后键床/独立音序是否适合当前工作流？ |
| Launchkey Mini 37 vs Akai MPK Mini Plus II | pads、琴键力度及工作流；AKAI 二代因过新暂缺成熟评测 |
| 上述任意 37 键 vs SMK-37 Pro | 低价多功能方案的键床、固件、连接稳定性是否能满足核心任务？ |

## 淘汰规则（形成最终短名单之前）

- 硬性淘汰：宽度超过 595 mm；键数超过 37；确凿无法在目标 Windows/DAW 上进行基本 MIDI 音符输入。
- 软性降级：琴键力度不稳定、映射太依赖单一 DAW、需要经常菜单操作、独立使用者反复复现未修复固件故障。
- 单个差评只能触发进一步验证，不能自动淘汰；刚上市产品在长期可靠性项保持「无证据」。
- 采用 **按任务的优缺点描述**，避免使用没有测量方法的“9.5 分琴键”等数字评分。
- **最终目标：3–5 款不同价值取向的短名单。完成后，另开价格研究文件按国内四站核 SKU，不把报价提前写进本表。**
