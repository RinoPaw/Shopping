## 用户最新明确需求

用户已明确：**不需要机身自带音源、不需要鼓垫、不需要蓝牙、不需要内置电池**。只需使用 Windows 上的 FL Studio 或 Cubase 输入旋律、和弦（零基础）；最多 37 键，机身宽 ≤595 mm，**目标预算约 ¥500（尚未说明是否为绝对上限）**，二手可考虑。

- “不用音源”是指不需要**控制器内置声音发生器**；电脑仍需虚拟乐器/音源插件才会发声。
- USB 供电符合“不需要电池”；并不要求设备不带八度切换、弯音轮或旋钮。附带的非必要功能没有直接排除资格，但**不为它们支付额外预算**。
- 重要顺序：**键床好弹、黑键/和弦不误碰、力度稳定、USB-MIDI 可靠性、37 键音域、价格与售后**。复杂 DAW 远程脚本、鼓垫、独立音序、蓝牙电池均降低权重。

## 暂时降级的型号及具体理由

- **M-VAVE SMK-37 Pro / Elite、森林岛 K32 Play**：机身内置 FM 音源、无线、电池、pads、独立音序等都是用户明确不需要的卖点，增加了界面和故障/学习层级。尤其 SMK-37 Pro 还必须核 V016 固件与有线 Note On 稳定性。如果**正确 SKU 极便宜且基本 MIDI 可靠**可以重新考虑，但现在不按“功能多”加分。
- **MiniLab 37 / Launchkey 37 MK4 / FLkey 2 37**：在宽预算下优势显著，此用户现在只要 MIDI 键床，且目标 ¥500，这些控制集成与 pads、推子在目前目标里价值低。即使外观高级也不构成多花 ¥800–1600 的理由。
- **25 键产品**：硬条件允许，但 37 键和弦空间的实际价值更高；低预算也能考虑 32 键，因此 25 键不作为主研究方向。

## 今后的客观琴键测试

1. 以 **37 键**优先，同类迷你键注意白键在黑键之间的最窄位置，以及中/小指按和弦时是否碰到邻键。
2. 在统一 MIDI 监视器上重复轻触、常规触、强触，比较键盘 Note On velocity 的可控区间；反复触发黑键，观察漏音、重复音、键间差异。
3. Windows 同 DAW 录音时，拔插 USB 后无需重建 MIDI 音符输入；旋钮/pads 无需做主要测试。
4. 旧机需要查 USB 接口松动、逐键重复发音、速度灵敏性劣化、是否有延音踏板接口（如果准备购买踏板）。
5. 在实际下单前验证配件、退换、商品来源及最终付款价。**先不下单。**
