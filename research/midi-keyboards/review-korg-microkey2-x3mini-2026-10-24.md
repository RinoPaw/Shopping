# ¥500 纯琴键 MIDI 控制器：KORG microKEY2-37 vs MIDIPLUS X3 mini（一代 / 二代）测评证据

**调研日期：2026-10-24。用户目标**：Windows / FL Studio 或 Cubase 输入旋律、和弦；≤37 键、≤595 mm 宽、¥500 左右；不用机身内置音源、鼓垫、蓝牙、电池；二手可接受。

**证据边界**：独立购买者文字评价、专业媒体/商家原文视频简介、厂商公告分别引用。未对三台设备进行实体对比，也未把 YouTube 视频描述当成已经完整看过/听过的视频内容。本次购物专用 Chrome 的 Bilibili 搜索导航超时，原有商品页保持未改动；没有安装驱动或执行任何系统更改。

## 研究最重要的事实

- KORG microKEY2-37 **符合功能极简条件**，但负面评价明确指向**迷你键手感/和弦手指空间**、KORG Kontrol Editor 的易用性、旧驱动与 Windows 的兼容。它没有能够支持“键床客观强于 MIDIPLUS”的证据。
- MIDIPLUS X3 mini **老款** 有较多真实买家评价和正向反馈：Thomann 截至本轮显示 **31 条顾客评分，均分 4.6/5**，**22 条文字评价**；一位 2024-11 的长期用户表示**部分键力度敏感度随年份下降**，与二手采购直接相关。
- MIDIPLUS X3 mini II **二代** 厂商 2026-04 发布的手册确认琴键和功能规格，但缺少有意义的长期独立使用样本。**不要将老款评分继承给二代。**
- Windows 11 24H2 及以后存在**2026 年重要驱动变更**：KORG 2026-03 公告及 Microsoft Windows MIDI Services 官方要求，**不要在新版 Windows 11 上安装旧 KORG USB-MIDI 驱动**；已经安装的依官方流程移除。历史 Windows 抱怨受驱动/操作系统影响，不可直接归咎硬件品质。

### 真实用户证据：支持与反对

- [Sound House 日本有线 microKEY2-37 商品评价](https://www.soundhouse.co.jp/products/detail/item/209189/)：**8 条评分均分约 3.5/5**（5 星 2，4 星 4，1 星 2）；**2025-01-04** 用户认为功能简单、无需其他设置；**2018-09-22** 用户觉得 USB 即插即用；**2021-10-15** 用户反映 **KORG Editor 难用、改 MIDI 通道和力度曲线故障**；**2020-04-30** 用户认为**琴键狭窄，按和弦手指空间不足，需要不自然收紧手指**，但认可做工；**2022-04-01** 用户遇到 Mac USB-C 转接链路通信问题。注意可见文字评论可能少于全部八条。
- [Kakaku 日本 2019-12-08 单个购买者评价](https://review.kakaku.com/review/K0000829170/ReviewCD%3D1281638/)：认可小巧便携，但觉得琴键触感“偏软、难弹”，与 Yamaha reface mini 琴键相比体验较差。这是**一个人**的主观意见。
- [Sweetwater microKEY 37 型号页面 11 条评价](https://www.sweetwater.com/store/detail/microKEY237--korg-microkey-37-keyboard-controller/reviews)：**均分约 3.6/5**；有用户觉得 37 键足够试和弦、轻巧，有用户报告 Windows 识别失败，也有用户 Windows 10 正常使用，2020 年有人不满意键床。**关键混代风险**：页面标题是 microKEY-37，货号 microKEY237，但较早评论文字存在“since first released”字样，可能涉及较早微型系列；请勿把全部历史 Windows 故障认作 **microKEY2 2015 之后单一型号**的故障率。
- [B&H 两名买家](https://www.bhphotovideo.com/c/product/1198375-REG/korg_korg_microkey237_usb_keyboard.html/overview)：一人称键盘实际触感好；另一人觉得小键廉价、没有标准 5 针 MIDI OUT，故退货。后者的 MIDI OUT 需求并非本次用户所需，可排除该条购后抱怨中的应用需求差异。

**综合**：高频优点是“**极简、37 键适合桌面、USB 直连、入门记谱**”；风险集中在 mini 键盘的**和弦操作空间**与个体感受冲突，以及有时需解决 MIDI 识别问题。**不能宣称 KORG 必然比 X3 mini 更好弹。**

### 重要软件事实：Windows 11 2026

- [KORG 2026-03 官方公告，2026-04 补充](https://www.korg.com/us/news/2026/0312/)：Windows 11 24H2 以后启用 Windows MIDI Services 后，**KORG 旧版 USB-MIDI Driver 可能冲突；不应重新安装旧驱动**，现存的旧驱动需按公告移除，改用 Windows 自带 MIDI 设备支持。
- [Microsoft Windows MIDI Services 已知问题](https://devblogs.microsoft.com/windows-music-dev/windows-midi-services-rollout-known-issues-and-workarounds/) 印证旧 KORG .DRV 与新 MIDI 服务冲突、设备不显示或应用等待很久。
- [KORG microKEY2 当前驱动下载页](https://www.korg.com/us/support/download/driver/0/531/3541/) 的页首也明确 **Windows 11 24H2 或更新：Do not install**。
- 具体设备可用性依用户系统版号、Windows Update 与 DAW 版本等；目前**并没有在用户电脑连接过实体 KORG**，故不能承诺即插即用 100%。

## 2. MIDIPLUS X3 mini 一代：好评较多，但二手质量有重要风险

### 实际使用与消费者评价

- [Thomann 真实购买者页面](https://www.thomannmusic.com/midiplus_x3_mini.htm)：2026-10 查看 **31 条顾客评分，均分 4.6/5**；有 22 条文字评论（页面默认只展示部分）。**2019-08-23** 购买者喜欢金属机身、旋钮紧致、mini 琴键回弹与较高质感，自述还无法评价长期耐久；**2019-10-28** 购买者觉得按键尺寸与 Arturia MiniLab 接近，尤其认可 37 键录入音符且没有额外鼓垫；**2024-11-06** 一名持有多年的使用者明确表示部分琴键灵敏性下降。这三条为不同日期的用户个体经验，不能求平均得“故障率”。
- [Felice Music Labs 日本自购使用文章](https://www.musicafelice.com/midiplus-keyboard/)，2018-04-30/2022 更新：选 37 键用于桌面，小型金属机身坚固、重量给人稳定感，认为琴键足以实时录 MIDI，旋钮比价位预期更结实；文章公开说明可能带**联盟链接**，不是无经济利益的随机样本。
- [Gearank 2022-07](https://gearank.com/gear/midiplus-x3-mini-37-key-midi-controller-keyboard/)：历史综合评价约 91/100（聚合 125+ rating/reviews，来源合并可能重复）。其低于 $100 MIDI 键盘推荐名单 2018–2022 连续上榜，最终被其他型号取代。**聚合分数不代表 125 个人都做过同场客观对照**。
- [国内贾逸可 / Midifan《12 款迷你 MIDI 键盘年度大 PK》](https://m.midifan.com/article_body.php?id=7579)：谈到 X mini 系列的键感接近 MiniLab、外壳坚固、基本 MIDI 控制丰富；但作者在 [2025 年 MIDIPLUS 品牌发布会](https://www.bilibili.com/video/BV1UusgzWEnZ/) 自述已担任**MIDIPLUS 设计总监**。作者身份随时间变化，本资料权重低于独立购机长期体验，不能以为完全中立。

### 对 ¥280 这台二手的意义

[闲鱼页面 ¥280 包邮 7-8 成新、裸机无 USB-B 线](https://www.goofish.com/item?id=1093473450064&categoryId=126858793)。
至少必须验证：
1. 37 个琴键逐键按下/抬起能否正确产生 MIDI Note On / Off，特别是重复连奏；
2. 同一键轻/中/重按的 velocity 是否有梯度；横向比较黑键、有无力度几乎恒定 127 或始终低于 20 的异常；
3. USB-B 接口是否松动、敲击桌面时有没有断连；所有旋钮和八度按钮功能；
4. USB 线另购是否值得。**不能用 Thomann 好评替代这台旧机的验收。**

## 4. 选择优先级与下一步

| 判定项 | KORG microKEY2-37 有线 | X3 mini 一代 | X3 mini II 二代 |
|---|---|---|---|
| 闲鱼真实目标商品价格 | **¥400 包邮** | **¥280 包邮，裸机** | **¥499 包邮，配件齐（自述）** |
| 客观键感 | 未进行同条件实机测试 | 未进行同条件实机测试 | 未进行同条件实机测试 |
| 有来源的手感观点 | 小巧简洁，但有“软、和弦拥挤”个体反馈 | 好评较密集，用户说接近 MiniLab 手感 | **独立样本很少** |
| 可靠性风险 | 旧驱动冲突可依新版 Windows 指引规避；实体旧机仍需逐键测试 | 老琴键灵敏度下降有长期负面个案、¥280 裸机磨损较明显 | 新机代数较近；个体二手状况、琴键和 USB 仍未实测 |
| 是否对需求过度设计 | 几乎没有 | 四旋钮六按钮是附赠，不需加分 | 五种力度曲线等是附加功能，不应高价购买 |
| 下一轮行动 | 优先验证那台 **¥400** 具体设备的所有键与 Windows MIDI | 与 KORG 同步拿到逐键轻/重力度演示，才判断 ¥120 差价 | 对比是否有全新 ¥500 内的正确 SKU 和退换保障 |

**不以品牌预设键床胜负**。目前可先关注 KORG microKEY2-37 ¥400（简洁、实价契合）和 X3 mini 一代 ¥280（键床口碑不错，但二手磨损风险），继续审查二代售价与第三方体验。没有任一产品达到可不经测试直接下单的证据标准。
